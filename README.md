# Sports Card Market OS

Evidence-first sports-card market intelligence system.

## Current baseline

The repository is being initialized from the tested v0.7.4 local baseline. The system prioritizes authoritative sold-data ingestion, precision-first entity resolution, comp adjudication, persistent market history, comparable/hierarchy intelligence, leakage-safe backtesting, recommendation accountability, and only then UI expansion.

The first published baseline archive is checksummed and CI-tested in this repository while the unpacked source tree is migrated into normal branch/PR development.

## Quality gate

No feature is considered shipped unless the test suite passes. Real-data correctness takes priority over surface polish.
